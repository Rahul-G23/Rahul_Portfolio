## Run Locally

Follow these steps to run the portfolio on your local machine.

**1. Clone the repository**

```bash
git clone https://github.com/Rahul-G23/Rahul_Portfolio.git
```

**2. Navigate to the project directory**

```bash
cd Rahul_Portfolio
```

**3. Open the project**

Open `index.html` using a local development server, such as the VS Code Live Server extension.

**4. View the website**

Open the local URL provided by your development server in a browser.
